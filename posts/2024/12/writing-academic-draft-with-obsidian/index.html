Using Obsidian to write academic draft

Runyu Ni
2024-12-15
english, obsidian, writing

This article is for the users who are using Zotero and Obsidian

Why I using Obsidian to write draft:

  • While LaTeX provides more elegant typesetting, its syntax is more complex, and compilation is required to verify the content’s correctness.
  • In Obsidian, Markdown allows for real-time preview while seamlessly integrating LaTeX for mathematical formulas.

The problem for using Obsidian

The mainly problem for using Obsidian to write an academic draft is references.

Solution

Install plugins Pandoc Plugin, Pandoc Reference List, ZotLit in third-party plugin marketplace of Obsidian.
Install plugins Better BibTex for Zotero and ZotLit for Zotero.
